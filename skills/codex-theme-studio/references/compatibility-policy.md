# 兼容性策略

## 两级改动

### 安全主题层

颜色、字体、字重、图片、圆角、密度、表面和选中态走主题变量。默认允许应用。选择器优先使用 Bundle ID、ARIA、`data-*` 语义标记和项目已经验证的稳定结构。

### 高级布局层

宽度、位置、网格、响应式、元素隐藏和 DOM 重排属于高级布局。只有用户明确要求时修改，并必须补充静态断言和实机证据。

## 通过标准

- 首页：Hero、原生问候语、全部原生建议卡、项目选择器和输入框可见；无重叠和水平溢出。
- 任务页：正文、代码、附件、菜单、文件标签、侧栏和输入框可读、可点击、可聚焦。
- 系统页：不错误出现 Hero、角色图或输入框；底色和文字对比稳定。
- 窗口：至少验证正常窗口和全屏。高级布局还要覆盖窄、中、宽三个宽度档。
- 运行：`doctor-macos.sh --require-live` 通过；`verify-dream-skin-macos.sh` 返回 `pass: true`。

## 兼容性结论

“已支持”只表示 trust report 中列出的 Codex 版本和页面证据已经通过。新版本 Codex 上首次运行属于待验证状态；如果稳定语义标记变化，保留安全主题层，关闭失效的高级布局规则，并进入修复流程。

无法取得实时 DOM 或截图证据时，不允许用“应该生效”代替验收。
