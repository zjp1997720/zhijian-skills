# 能力与安全边界

## 支持范围

- 官方 macOS Codex Desktop，Bundle ID 为 `com.openai.codex`。
- Codex 应用内已签名、且签名主体与应用一致的 Node.js 20 或更高版本。
- 颜色、字体栈、字重、图片、圆角、密度、首页 Hero、侧栏、任务正文、输入框和少量经实机确认的高级布局。
- 设计、安装、热更新、实机验证、暂停、恢复和受控版本回退。

## 权限边界

- 静态设计、测试、Doctor 和不启动 Codex 的安装可直接执行。
- 关闭或重启正在运行的 Codex 必须取得本次明确授权。
- 常驻管理器必须单独明确授权；一次安装授权不自动包含常驻。
- 对外发布、上传或创建公开仓库必须单独授权。

## 技术边界

注入器只监听 `127.0.0.1`，只连接通过身份探针的 `app://` Codex renderer，并校验端口进程归属。它不写官方应用包，不改 `app.asar`，不关闭签名校验，不安装来源不明的依赖。

CDP 对本机页面具有较高控制力。运行主题期间不要运行会扫描本机调试端口的不可信软件；不用主题时执行 Restore，关闭受管调试端口。

## 明确排除

Windows、Linux、ChatGPT 网页版、ZCode、豆包工作、第三方重打包 Codex、任意 Electron 应用注入、模型/账号/权限配置、对话内容处理、整页截图覆盖和用户任意 JavaScript。

遇到排除项时只说明边界，不尝试套用选择器或绕过签名验证。
