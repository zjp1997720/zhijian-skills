# GPT Image 2 提示词写法

依据 OpenAI《Image prompting》指南与 Cookbook《GPT Image Generation Models Prompting Guide》，并补充 2026-10 封面探索与写法对照实验的实测结论。每次写提示词前读本文件。

## 结构

1. **用途与成品形态先行**：写明载体、读者和呈现尺寸（如“视频号竖版封面，信息流里只以约 240 像素宽出现”），要“可直接发布的成品设计稿”。用途决定精致度。
2. **分段顺序**：场景/背景 → 主体 → 关键细节 → 约束；复杂需求用带标签的短段落。
3. **层级与版式**：写清标题占画面多少、在哪、字重、颜色（十六进制色值），以及文字与人物的前后关系。
4. **视觉事实**：写材质、光、镜头、取景、手的位置和视线；写实就直说“写实摄影”。相机参数只作外观提示，氛围词替代不了版式描述。
5. **参考图编号并说明角色**：“图1：讲师本人照片，只作身份依据”；列出锁定项（五官、脸型、发型、肤质）与可变项。

## 三层写法（封面、海报、课件页）

带文字的设计稿按三层写，三层齐全才稳。依据：2026-10-23 对照实验，同内容、同风格目标、32 张盲评，三层齐全的写法排第一；同样画面与文字但只写一句风格的短提示，以及只写风格与主题、不给画面的长提示，都明显落后；只给主题的写法 8/8 张自己编小字，1 张乱码。

1. **设计规则**：写成可检查的数字和硬约束。
   - 一个视觉焦点，占画面约 40%—55%；留白至少三分之一。
   - 三级文字层级：主标题最大；副标题约为主标题的三分之一；信息与页脚最小。层级靠字号与留白，不靠描边、阴影、底框。
   - 文字区位置、所有文字对齐的同一条竖线、页边距约为画面宽度的 6%。
   - 3—4 个十六进制色值，各标角色（底色、文字、主视觉、点缀），其余饱和色一律不加。
   - 画风与材质、光线各一句。
   数字比“色彩性格”“克制通透”这类描述更稳：同样三层齐全时，写色值与比例的版本胜过写描述的版本。
2. **画面主意**：一句具体画面，写清画什么物、什么光、什么材质，最好带一个对应主题的隐喻，如“一笔浓墨圆相，右下三点淡墨，像一个人和三个助手”。缺这一层，模型自选最常见的意象：卡通机器人、星空粒子、泛光斑。
3. **精确文字**：按「文字」一节逐行给引号文字，再写“除以上文字外不出现任何文字，不要补足次级小字”。

结尾写优先级：“用途、准确文字与画幅优先；设计规则与画面主意保持不变。”

### 复用、比稿与多页

- 设计规则层存成风格模板，复用时只换画面主意和文字。
- 比稿：同一份画面主意与文字套 2—4 个风格模板并行出图，按缩略图并排挑方向。
- 多页课件每页单独生成。每页都附完整设计规则和整套页面清单（第几页、讲什么），写“本次只生成第 N 页”；规则里写“内容多时双栏或四象限，内容少时单一大标题加远端注释”，并固定边距、基线、页脚位置，跨页才一致。一张图里拼多页缩略图只作概览，正文字会小到不可读。

## 文字

模型能一次排出含中文标题的完整设计，默认让它出带字成品。

- 中文原样放进引号，直接贴字，不先用英文描述。
- 每行标角色（栏目、主标题、引子、身份），写位置、字号比例、字重、色值；字体名会生效（“宋体特粗”“黑体”）。
- 用“中式极简”“编辑风格”等描述风格，避开国家风格词（会混入假名）。
- 结尾固定约束：只出现引号内文字、逐字准确、每段只出现一次、无水印无 Logo；附英文 `Exact text only. No extra words. No duplicate text. No watermark.`
- 生成后放大逐字核对；错字用“只改这个字，其余不变”局部修。

## 头像与系列图

依据 2026-10-11 七位 AI 同事头像实跑：第一版脸型、服装、配色、构图几乎一致，被判“没有区分度”；“中国浪漫水彩”被当成题材，背景出现梅花、远山、竹子、灯笼、盘扣。

### 头像

- 用途句写清：“正方形头像，会被裁成圆形，在聊天列表里只以约 40 像素出现”。
- 构图：主体头肩居中，脸部占画面约 50%—60%，四角留白或纯色，圆形裁切后不切掉头顶、耳朵和道具。
- 辨认靠大形，不靠细节：轮廓（发型、年龄、体型、姿态）、一个主色、一件标志性道具；背景纯色或极简渐变，无文字。
- 人物写明族裔与年龄（如“当代中国人，东亚面孔，约 40 岁”）。只写服装和气质时，水彩和插画常默认画成欧美面孔；同批七张里有三张因此重画。
- 生成后缩到 40 像素并按圆形遮罩看一遍，认不出是谁就加大轮廓或主色差异。

### 系列区分度

1. **先列区分表，再写提示词。** 每个角色一行，列：主色（色值）、轮廓（发型/年龄/体型/姿态）、标志性道具、表情。完成条件：任意两个角色在主色、轮廓、道具三列中至少两列不同。
2. 每张提示词由“共用画风段 + 该角色专属段”组成；共用段一字不改，专属段逐项抄区分表。
3. 用参考图统一画风时，在约束段末尾写：“参考图只锁画风（笔触、用色方式、质感）；不要沿用参考图的人物、服装、配色、背景元素。”
4. 防漂移按「迭代」一节：每 2—3 张重贴完整提示词。

### 风格词与题材词分开

- “XX 风格”只约束笔触、用色、质感，例如“中国浪漫水彩：湿画法晕染、留白、透明叠色、纸纹”。
- 主体、服装、背景在各自段落单独写，用中性或现代描述（如“现代简约衬衫，浅色纯背景”）。
- 约束段兜底：“背景与服饰不出现梅花、远山、竹子、灯笼、盘扣等传统文化元素。”按所用风格替换为该文化的服饰、建筑、植物、器物。
- 与「文字」一节的“避开国家风格词”不同：那条防字体混入假名，这条防画风带出题材。

## 已知局限

- 模型画不准指定数量的图标（要 67 个画 66 个，要 65 个画 70 个）；数据只写成数字文本，图形用比例条等不可数形式。
- 前景物体会整字挡住大字；关键文字放在人物侧面，脸部完整露出。
- 经 Codex 通道 quality 与 size 被服务端设为 auto（见 `api-notes.md`），质量靠提示词与复核保证。

## 迭代

一次只改一个变量，每轮重述保留清单；系列图每 2—3 张重贴完整提示词防漂移；风格探索时把多个方向并排，再按信息流缩略图大小对比。
