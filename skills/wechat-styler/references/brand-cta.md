# 品牌首尾 GIF

已确认默认行为：每次公众号排版自动插入一张开头 GIF 和一张结尾 GIF，正文内容保持不变。由 `scripts/brand-cta.mjs` 实际执行，不依赖 Agent 手工追加。

## 开场互斥

- 普通转换与 `--components`：开头 GIF + 正文 + 结尾 GIF。
- 用户明确要求原小蓝打招呼或其他主题开场：传 `--cover --cover-template xiaolan-terminal`（或所选模板），保留 SVG 开场和结尾 GIF，省略开头 GIF。
- 输入已含带 animate 的 SVG：同样省略开头 GIF。
- 用户要求不放关注/互动引导：传 `--brand-cta none`；仅需结尾：`--brand-cta ending`。
- 开场 GIF 与 SVG 不叠放；重复处理已有受管 GIF 时先去重。转换器只管理这一套素材，保留用户其他图片。

## 素材与交付

`assets/brand-cta/manifest.json` 是素材版本、URL、尺寸、SHA256 的事实源；同目录保留可独立安装的 GIF 原件。默认输出使用已核验的 HTTPS 图床 URL，不引用开发机器路径，不在每次排版时上传。

主标题思源宋体 800，副标题仓耳今楷 W05；两倍分辨率、白底、2.4 秒循环。机身使用固定底层，只替换手臂与眼睛区域。上传前须验证实际解码时长、机身静止阶段的一致性、移动端显示及远端 SHA256。

素材可走已有微信图片转存流程，保持 GIF 格式。首尾引导图不作为文章封面；封面使用正文内容图或显式指定图片。纯 HTML 本地预览不代表微信公众号真实读者端验收，发布与保存草稿仍沿用原授权边界。
