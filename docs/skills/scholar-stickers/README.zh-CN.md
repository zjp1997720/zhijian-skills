# Scholar Stickers · 知识人物贴纸幻灯片生成器

输入人物或学科概念，自动查证史料、生成统一素描贴纸肖像，产出 16:9 课堂投影级交互幻灯片（总览贴纸墙 + 人物详情页，零滚动、键盘翻页、后排可读）。

## 安装

```bash
npx skills add zjp1997720/zhijian-skills --skill scholar-stickers
```

## 环境要求

- Node.js 18+（用于 `npx skills`）
- 支持 `SKILL.md` 规范的 Agent 环境（如 WorkBuddy、Claude Code、Codex 等）
- 文生图能力（各平台自带的多模态生图工具、API 或本地生图工具）

## 核心功能

- **单文件 16:9 交互幻灯片**：总览贴纸墙点击直达人物页，支持键盘翻页（`←`/`→`、`Esc` 返回总览、`Home`/`End`）与自适应居中缩放（`fitStage`）。
- **结构化资料整理**：自动提取五段式结构（生平、3 条核心贡献、2 条金句名言、2 本代表著作、1 条当代启示），字数严格受限，杜绝内容溢出。
- **铅笔素描贴纸风肖像**：内置统一 Prompt 模板，生成白边贴纸质感素描头像（768×960 PNG）。
- **投影级视觉规范**：内置 `warm-classic` 暖米经典主题及多种学科配色，金句 28px、正文 22px，保障大教室后排清晰可读。

## 工作机制

1. **查证资料**：通过搜索或知识库整理人物五段式卡片，拿不准的史实标记 `[待核实]`。
2. **生成肖像**：调用文生图能力，按照统一铅笔素描贴纸 Prompt 生成 768×960 人物肖像。
3. **页面组装**：将主题、元数据和结构化数组注入内置的 `template.html` 模板，生成无外部依赖的自包含 HTML 文件。
4. **预览与交付**：本地浏览器预览排查，确认无误后交付 HTML 课件及配套素材。

## 典型使用指令

- 「用 scholar-stickers 做 5 位教育家的课堂介绍页，领域是教育哲学，标题『哲学，从惊讶与疑惑开始』」
- 「帮我做一份唐宋八大家的课堂人物讲解 HTML 页面，使用 scholar-stickers 技能」
- 「把牛顿、麦克斯韦、爱因斯坦、玻尔做成物理学史互动演示页」

## 边界与注意事项

- **史实核验**：生成的人物生平、名言出处与著作需经教师人工核验后引入正式课堂。
- **生成随机性**：大模型生成具有一定随机性，本 Skill 通过锁定结构、流程、格式和视觉规范来确保高度确定性的输出质量。
- **零滚动铁律**：页面严格杜绝滚动条，单屏放不下的内容通过折叠或提炼呈现。
